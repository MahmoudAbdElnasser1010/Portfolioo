Overview

Nimbus's original dashboard had grown organically over three years, and it showed — inconsistent components, slow chart rendering, and a navigation model that only made sense to the team that built it.

I was brought on to lead a full redesign: rethink the information architecture, build a proper design system, and work directly with engineering to ship it in production-ready React components.

The Challenge

The core challenge was reducing time-to-insight for users staring at dense, high-frequency data without dumbing the product down for power users who lived in it all day.

  • Legacy UI had 40+ one-off components with no shared source of truth.
  • Chart rendering slowed to a crawl past 10k data points.
  • New users took 3+ sessions to find their most-used reports.

The Approach

I started with two weeks of user interviews and session recordings, then moved into low-fidelity flows before touching visual design. Every major screen was prototyped in the browser to test real data, not filler content.

  • Built a token-based design system shared between Figma and the React codebase.
  • Redesigned the report navigation around saved views and search instead of nested menus.
  • Partnered with engineering to move heavy charts to a canvas-based renderer.
